# 许继电气异常检测展示：页面总纲

## 1. 目标与主线

网站完整展示风电异常检测实验链路：

原始数据 → 电站筛选 → 字段清洗 → 时间对齐 → 连续数据段 → 28 维研究数据集 → 训练集与测试集 → 归一化 → 异常构造 → 滑动窗口 → 模型训练 → 重建误差 → 异常分数 → 阈值判定 → 成果总览 → 报告指标。

每页只讲一个操作或一个结果。页面保留真实数据片段、关键字段和可见的前后变化。文案直接说明数据、操作和结果，不额外添加解释性副标题。

首版采用完整讲解路径，不设置“简版／完整”两套路线。阶段导航只用于定位，不改变内容顺序。

## 2. 数据与结果绑定规则

### 2.1 首版主线

主线采用最新异常检测报告中的第二批风电数据：

- 目标电站：41 号电站。
- 原始类别：`weatherdata`、`weatherforecast`、`powerstat`、`short`、`ultrashort`。
- 实际进入异常检测合并表：`weatherdata`、`weatherforecast`、`short`。
- 时间粒度：15 分钟。
- 最终数据：8,759 行，合并表 42 列，其中 28 个模型字段。
- 划分：按时间顺序前 70% 训练、后 30% 测试，即 6,131 行训练、2,628 行测试。
- 特征组成：实际功率、预测功率、13 个实测气象字段、13 个预报气象字段。

报告明确写出“后续实验与部署应使用 28 特征”。因此 28 维是报告的目标展示版本，不代表服务器当前已经保存了三个模型同版本的完整回放文件。

### 2.2 旧实验

服务器仍有一条旧风电实验链路：7 维、7,007 行训练、1,752 行测试、80%／20% 划分，并保存了 STMem-AD 检查点和部分回放文件。它与报告主线的 28 维、70%／30% 版本分开标记，不在首版主线中混用。

### 2.3 报告结果与服务器资产

报告已经给出三种模型在 28 特征版本上的结果：

| 模型 | 窗口 | 异常注入比例 | Precision | Recall | F1 | AUC |
|---|---:|---:|---:|---:|---:|---:|
| STAM-AD | 96 | 0.65 | 0.8795 | 0.8475 | 0.8632 | 0.9084 |
| SMST-AD | 96 | 0.70 | 0.8222 | 0.8475 | 0.8347 | 0.8995 |
| STMem-AD | 96 | 0.65 | 0.8011 | 0.8475 | 0.8237 | 0.8932 |

这些是报告级结果。服务器当前可见目录没有为三个模型都配齐“同一数据版本、同一异常配置、同一窗口、同一权重、重建值、分数和标签”的回放包。接入页面前必须建立结果清单，逐项绑定来源。

### 2.4 必须固定的实现事实

- 风电第二批数据的关键缺失记录按报告删除，不写成统一补零。
- 窗口转换代码在序列边界重复首个观测值，补足窗口长度。
- TCN 因果卷积内部存在左侧零填充，这是模型运算中的补齐，与窗口转换不同。
- 标签矩阵初始化为全 0，表示当前没有插入异常标签。
- 窗口重建误差按每个时间点被覆盖的窗口数做算术平均，再按特征维度平均为单点异常分数。
- 训练代码当前对 STAM-AD、SMST-AD 和旧版 STMem-AD 都出现训练轮次重新插入异常的调用。报告对 STMem-AD 的设计描述是正常数据建模，正式页面以最终核定的实验版本为准。

## 4. 设计语言约束

- 统一浅色背景、深色正文和单一界面强调色。
- 原始值、重建值、阈值、真实标签、检测标签使用固定颜色和线型。
- 异常颜色只用于异常区间、异常标签和检测告警。
- 每页保留一个主图或主表，一个主要操作，一个结论。
- 详情通过展开区域承载字段名、公式、文件名和参数，不在主视图堆叠说明。
- 页面标题直接写动作或结果，不用额外的宣传性副标题。
- 动效只表现数据发生的变化：筛选、对齐、窗口移动、异常插入、重建、回放。
- 动效支持暂停、拖动和减少动效设置。
- 页面不使用装饰性渐变、科技背景、无意义计数动画和重复卡片。

## 6. 后续替换契约

1. 28 维三模型逐点输出当前未配齐；首版以已有输入、原始代码规则与报告成绩完整展示。
2. 新结果包需绑定字段顺序、窗口、模型、标签、重建值、分数、阈值和指标，校验通过后替换对应页组件。
3. STMem-AD 报告设计与旧入口调用分别注明来源；不把历史检查点标作报告同版权重。
4. POT/SPOT 运行阈值与报告阈值扫描成绩分别记录。
5. 功率预测数据、异常检测重建值与异常分数保持不同含义，禁止互换图例。
